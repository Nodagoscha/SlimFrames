# SlimFrames

Minimale Unit Frames fuer World of Warcraft: Player, Target, Target-of-Target und Focus.

- `/slim` oeffnet die Einstellungen (Skalierung, Breite, Klassenfarben, Frames entsperren).
- Einstellungen werden in `SlimFramesDB` gespeichert.

## Installation

Ordner nach `World of Warcraft/<Version>/Interface/AddOns/SlimFrames` kopieren.
